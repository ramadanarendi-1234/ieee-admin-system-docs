# 📋 Sistem Informasi Administrasi & Surat Menyurat
## IEEE Student Branch IPB University

> Dokumentasi lengkap sistem administrasi dan alur surat menyurat organisasi IEEE Student Branch IPB University — mencakup SOP, diagram alur sistem informasi, dan panduan pengarsipan digital.

## 📁 Struktur Repositori


---

## 🎯 Tujuan Sistem

Sistem ini dirancang untuk:
- Menstandarisasi alur administrasi surat menyurat di IEEE Student Branch IPB
- Memastikan setiap surat tercatat, terarsip, dan dapat ditelusuri
- Mempercepat proses disposisi dan tindak lanjut surat
- Mendokumentasikan seluruh korespondensi organisasi secara terstruktur
